# @agentrouter/dashboard

Next.js dashboard for AgentRouter: a dark "trading terminal" with the provider table, live
request feed, per-model price index, a SLASHED banner, and an HCS audit-trail panel. Consumes
the exchange SSE feed and Mirror Node REST.

```bash
pnpm dashboard        # http://localhost:3000
```

See the root [`README.md`](../../README.md) and [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).
Component + styling conventions: [`docs/FRONTEND.md`](../../docs/FRONTEND.md).
